# Biblioteca IPF — TP4 (React Native + Expo Router)

App del instituto: el alumnado consulta el catálogo, reserva libros y recibe un recordatorio de devolución. El personal entrega los ejemplares respetando el orden de las listas de espera.

## Versión del SDK

- Expo SDK **58** (`expo ~58.0.26`, React Native `0.88.1`, `expo-router ~58.0.32`).
- Módulos nativos: solo `expo-camera` y `expo-notifications`.
- Instalación de paquetes: siempre `npx expo install <paquete>`.

## Arranque

```bash
npx expo install --fix
npx expo start
```

Se prueba en **Expo Go** en un teléfono real. Los cambios en `app.json` (plugins y permisos) requieren reiniciar el bundler; si se usa development build, requieren rebuild.

## Árbol de rutas (`src/app`)

Generated by Expo Router. Source: `src/app/`.

```text
src/app/
├── _layout.tsx                    Stack raíz: BibliotecaProvider, anchor "(tabs)", Stack.Protected
├── +not-found.tsx                 404 que muestra la ruta inexistente
├── buscar.tsx                     /buscar?q= — búsqueda en la URL (stack raíz)
├── escanear.tsx                   /escanear — cámara EAN-13 + ingreso manual
├── login.tsx                      /login — modal, solo sin sesión
├── mostrador.tsx                  /mostrador — solo con sesión
├── reserva.tsx                    /reserva — Redirect a /reservas
├── permisos/[recurso].tsx         /permisos/camara | /permisos/notificaciones (modal)
├── reservar/[isbn].tsx            /reservar/[isbn] — confirmación (modal)
└── (tabs)/
    ├── _layout.tsx                Tabs: Catálogo y Mis reservas (expo-router/js-tabs)
    ├── reservas.tsx               /reservas
    └── (catalog)/
        ├── _layout.tsx            Stack propio de la tab Catálogo (link "Personal" en el header)
        ├── index.tsx              / — catálogo con estados y vistos recientemente
        └── libro/[isbn].tsx       /libro/[isbn] — detalle validado
```

El `anchor: '(tabs)'` en `src/app/_layout.tsx` hace que un deep link a `/buscar` deje las pestañas debajo en la pila.

## Permisos y mínimo privilegio

`app.json` declara:

- `plugins`: `expo-router`, `expo-camera`, `expo-notifications`, `expo-splash-screen`.
- `expo-camera.cameraPermission`: "Usamos tu cámara para leer el código de barras del libro y abrir su detalle."
- `expo-camera.microphonePermission: false` y `recordAudioAndroid: false`: la app solo lee códigos de barras, nunca graba audio ni video.
- `android.blockedPermissions`: se bloquean `RECORD_AUDIO`, ubicación (`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`), galería (`READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO`, `READ_MEDIA_AUDIO`, `READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`), contactos (`READ_CONTACTS`), SMS (`READ_SMS`) y llamadas (`CALL_PHONE`). Ninguno es necesario para las dos funciones de la app; bloquearlos reduce la superficie de permisos y evita rechazos en tiendas.
- La única pantalla de permisos es `/permisos/[recurso]`, con `camara` y `notificaciones`. El permiso de notificaciones **solo** se pide al activar "Recordarme" en un préstamo.

## Credenciales y datos de prueba

- Personal: usuario `admin`, clave `ipf2024` (en `src/constants/personal.ts`).
- Usuario alumno: identificador `Yo` (en `src/constants/alumno.ts`).
- `src/data/libros.ts` tiene 15 libros: 13 de catálogo base y 2 placeholders para libros físicos. Completar `LIBRO_REAL_1` y `LIBRO_REAL_2` con los ISBN reales de dos libros a mano y el nombre/apellido en `src/constants/alumno.ts` antes de entregar.
